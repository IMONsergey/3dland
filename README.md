# ЗАВОД 2040
### Интерактивный атлас промышленного будущего

[Открыть демоверсию](https://imonsergey.github.io/3dland/) · [Сборки и публикация](https://github.com/IMONsergey/3dland/actions)

Концептуальная веб-платформа по брифу «Проект 03. Завод 2040». Принцип: будущее промышленности рассматривается через **пару «новая возможность + новая уязвимость»**. Визуальный жанр вдохновлён Earth 2050, но дизайн, модель предприятия и интерактивные механики разработаны отдельно.

**Актуальная визуальная система:** иммерсивная 3D-сцена без постоянных панелей; лёгкая навигация, контекстная карточка при выборе объекта и самостоятельный светлый редакционный атлас. Разбор причинной цепочки киберриска скрыт до запроса читателя. Анализ референсов Kaspersky и причины решений собраны в [DESIGN_RESEARCH.md](./DESIGN_RESEARCH.md).

## Что уже работает

### Пространственный мир
- Интерактивное процедурное 3D-предприятие: доменный комплекс, цех прокатки, роботизированные участки, склады, энергетика, логистика, водоподготовка и инфраструктура.
- Дополнительные инженерные слои: фермы, мостовой кран, непрерывный прокат, трубопроводы, лестницы, платформы, площадки обслуживания, ёмкости, порт, железнодорожный терминал, линии электропередачи, промышленное освещение.
- Анимированные дроны, роботы, транспорт, металл на прокатной линии, дым, перемещение крановой тележки.
- Выбор физического объекта или маркера, плавная камера, вращение, перемещение, приближение и возврат к общему виду.
- Дополнительный «кибер»-слой: связи между системами подсвечиваются при просмотре уязвимости выбранного узла.
- Режим совместимости с интерактивным двухмерным планом при отсутствии WebGL.

### Сценарии времени
- Горизонты **2030 / 2035 / 2040** с разными сюжетами и новыми элементами среды: больше автономного транспорта и дронов, меньше операторов на производстве, цифровые надстройки, адаптивные подсистемы.
- Пошаговый маршрут по объектам и воспроизведение смены временных горизонтов.
- Глубокая ссылка на конкретную точку и год: параметры query string year и node.

### Исследовательская лаборатория
- **14 промышленных узлов и 42 прогнозных сценария**. Каждый прогноз имеет технологический и киберфизический слой.
- Каталог с поиском по технологиям и фильтрами по производству, автономизации, инфраструктуре.
- Сравнение 2030 / 2035 / 2040 для каждого узла.
- Модель риска из четырёх слоёв: точка взаимодействия → граница доверия → физическое последствие → принцип защиты.
- Сведения об оборудовании, контрольных мерах, связанных системах и исследовательских вопросах.
- Методология и отраслевой каталог с честными статусами доступности.
- Адаптивный интерфейс для мобильных устройств и планшетов.

## Текущие границы прототипа

**Одна отрасль детально:** металлургия. Для ТЭК, химии, энергетики, пищевой промышленности и водоканалов предусмотрена структура дальнейшего развития, но отдельные 3D-миры пока не построены.

**Технологические прогнозы гипотетические.** Тексты и цепочки риска подготовлены как концептуальные примеры. Это не официальный прогноз или рекомендация по информационной безопасности Kaspersky. Перед клиентским использованием нужен review инженеров технологического производства и экспертов ICS/OT.

**Сцена художественная.** Процедурные 3D-модели не являются CAD-моделями конкретного завода. Архитектура предназначена для демонстрации интерактивного жанра, а не для инженерного проектирования. Для финального продукта уровня студийного CGI потребуются индивидуальные визуальные ассеты, техпроцессные референсы и отдельная оптимизация WebGL.

**Нет серверной CMS.** Сейчас структурированный контент редактируется в репозитории; авторизация, публикационные права, модерация и серверное хранение не заявлены как готовые.

## Технологии

- TypeScript, React 19, Vite 6.
- Three.js, @react-three/fiber, @react-three/drei.
- Procedural geometry, animated parametric objects and links.
- Контентные модели в src/data/atlas.ts, src/data/extraNodes.ts и src/data/research.ts.
- Отдельная отложенно загружаемая JS-сборка исследовательского атласа; стили загружаются заранее для отсутствия визуальной задержки.
- CSS adaptive layouts, keyboard navigation, reduced-motion support.
- GitHub Actions → GitHub Pages.

## Локальный запуск

Требуется Node.js 20+.

    npm ci
    npm run dev
    npm run build
    npm run preview

Для проверки в браузере с установленным Google Chrome:

    npm run test:smoke
    npm run test:deep
    npm run test:release
    npm run test:design

По умолчанию проверка использует Google Chrome из стандартного macOS-пути; альтернативный бинарник указывается в переменной CHROME_BIN. Локальный Vite по умолчанию используется на http://127.0.0.1:4317/3dland/ при запуске с флагом --port 4317.

## Управление

- ЛКМ и перемещение мыши — вращение камеры.
- ПКМ и перемещение мыши — сдвиг камеры.
- Колесо / pinch — масштаб.
- Клик по объекту / маркеру — карточка прогноза и фокус камеры.
- Стрелки влево / вправо — 2030, 2035 или 2040.
- ESC — возврат к обзору; в лаборатории ESC возвращает к сцене.
- Кнопка «Лаборатория» — каталог, исследование и сравнение горизонтов.
- Кнопка сетки — показать все 14 маркеров на 3D-сцене.

## Следующие производственные этапы

1. Арт-дирекшен final CGI и промышленная детализация на основе настоящей схемы конкретного типа предприятия.
2. Полноценные пространственные преобразования предприятия между временными горизонтами, motion design и cinematic sequences.
3. Отдельные среды для пяти остальных отраслей.
4. CMS с версиями прогнозов, визуальной разметкой 3D-маркеров, правами пользователей, черновиками, предпросмотром, экспертным согласованием.
5. Аудит производительности в реальных мобильных браузерах, web vitals, сквозные визуальные и e2e-тесты.
6. Экспертное подтверждение промышленных процессов, терминологии и гипотез.

В проекте нет официальных логотипов Kaspersky, копий изображений Earth 2050, сторонних 3D-моделей или утверждения об авторстве клиента.
