# ЗАВОД 2040 — интерактивный атлас промышленного будущего

Рабочий демонстрационный прототип по концепции «Проект 03. Завод 2040», вдохновлённый механикой Earth 2050.

**Демо:** https://imonsergey.github.io/3dland/

## Что реализовано

- Процедурная 3D-сцена металлургического предприятия в браузере (React Three Fiber / Three.js).
- Производственные зоны: доменный комплекс, прокатный цех, роботизированный участок, энергетический центр, логистический терминал, силосные хранилища, диспетчерская.
- Интерактивные маркеры и фокус камеры, панорамирование, вращение и приближение.
- Три временных горизонта (2030, 2035, 2040), визуальные изменения техники, дронов и наложений, смена содержания прогнозов.
- Восемь точек с 24 сценариями, каждый из которых описан парой «возможность + киберриск».
- Пошаговый маршрут по точкам, переключение сценариев, глубокие ссылки на год и точку.
- Контентная структура для шести отраслей, при этом детально сделана только металлургия — остальные помечены «в разработке».
- Мобильная версия, клавиатурное управление, reduced-motion.
- Автоматическая публикация через GitHub Pages.

## Ограничения этой сборки

Это концептуальный прототип, а не утверждённый компанией Kaspersky прогноз и не полнофункциональная промышленная модель. Тексты прогнозов — гипотетические демонстрационные сценарии; перед публикацией под брендом клиента их должны проверить отраслевые эксперты. 3D-модели стилизованные процедурные, не инженерно точные. Полноценной CMS с серверным сохранением пока нет, контент редактируется в файле src/data/atlas.ts.

## Запуск

Требуется Node.js 20+.

1. npm install
2. npm run dev
3. npm run build
4. npm run preview
5. npm run test:smoke (локальная проверка в Google Chrome)

Основные файлы: src/components/IndustrialWorld.tsx (3D-сцена), src/data/atlas.ts (прогнозы), src/App.tsx (интерфейс), src/styles.css (дизайн), .github/workflows/deploy.yml (публикация).

## Управление

- ЛКМ + движение: вращение камеры; ПКМ + движение: перемещение карты.
- Колесо / pinch: масштаб.
- Клик по маркеру: прогноз и фокус камеры.
- Стрелки влево / вправо: переключение года.
- ESC: возврат к обзору.
- Начать исследование: последовательный маршрут по узлам.

## Дальнейшее развитие

1. Финальные 3D-модели с детализацией уровня студийного CGI.
2. Перестройка геометрии и состояний сцен при смене года.
3. Поочерёдное создание остальных пяти отраслей.
4. Экспертный review и ссылки на исследования.
5. CMS с ролями, черновиками, изображениями и предпросмотром.
6. Кросс-девайс QA, E2E-тесты, мониторинг WebGL.

В проект не включены сторонние 3D-модели или логотипы. Концепт подготовлен для внутренней демонстрации. Фирменный стиль клиента не утверждён.
